Movies Explorer (React + TMDB API)

A web application for searching and viewing movie information using The Movie Database (TMDB) API.

🔗 Live Demo
https://korotkova-iuliia.github.io/goit-react-hw-05-movies/


🛠️ Tech Stacka

React
React Router
Styled Components
Axios
TMDB REST API
Environment variables (.env)
Custom React hooks (useFetchMovieById, useFetchCast, etc.)

✨ Features
Browse trending movies
Search movies by title

Movie details page: 
overview 
poster
release date
rating 

Additional movie information:
Cast
Reviews
Smooth navigation with return-to-previous-page support
Partially responsive layout
